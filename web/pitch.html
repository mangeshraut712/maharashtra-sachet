Maharashtra Civic Alerts

Independent English/Marathi hub for official Maharashtra public warnings, district search and citizen-service directories.

This is not a government website and not emergency dispatch. In danger call 112. An empty bulletin is not an all-clear.

Builder: Mangesh Raut · Live on Cloudflare Workers

The problem

Residents should not have to guess which feed is live

Scattered official sources

National, state and municipal pages sit apart. Weather-only dashboards miss civic disruptions.

Empty can look safe

A quiet map is misleading when a source is stale, disabled or only covering some hazards.

Place names are ambiguous

Navi Mumbai spans districts. Village names are not the same as verified ward boundaries.

Language gap

Residents need the original warning in English or Marathi, not a rewritten AI summary.

What we built

A place-aware bulletin that states its coverage

  • Official CAP lifecycle: actual, update, cancel, expiry.
  • District search plus place aliases (Sawantwadi, Marunji, Navi Mumbai).
  • Source-health strip before anyone reads “no alerts”.
  • Twelve citizen-service directories with live vs directory-only labels.
  • Safe rendering, offline snapshot cache, bilingual UI.
  • Labelled local demo fixtures that never enter production.

Live product

Production hub

Hosted on Cloudflare Workers + D1. Minute cron plus bounded heal-on-read. Vercel is not required.

Search honesty

Places map to districts, not invented village polygons

Source health

Marathi

Same bulletin, resident language

Limits we keep public

What this project does not do

  • No government affiliation, cell broadcast or 112 dispatch.
  • No complete village or ward map.
  • CWC and CPCB stay disabled until a reviewed adapter exists.
  • No background Web Push after the tab closes.
  • No generative rewrite of emergency instructions.
  • The repository predates the event; event work was honesty, realtime ingest, place search and a labelled demo.
