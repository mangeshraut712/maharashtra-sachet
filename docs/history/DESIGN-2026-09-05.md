# Maharashtra public-service design refresh

The user requested a Maharashtra government-website feel for the existing independent civic alert hub.

## References inspected

- [Maharashtra State Disaster Management Authority](https://sdma.maharashtra.gov.in/en/): visually inspected masthead, bilingual title, sand navigation, amber active item, prominent update strip, service groups and footer structure.
- [Maharashtra Public Health Department](https://phd.maharashtra.gov.in/en/): inspected the bilingual identity, public-service navigation and structured directory/document sections.
- [Urban Development Department](https://urban.maharashtra.gov.in/): inspected Marathi-facing navigation and grouped citizen/municipal information.

The design adapts these information-layout conventions. It retains this project's original icon and explicit independent-project identity. No government emblems, department seals, official portraits, NIC credit or government ownership claims are copied.

## Changes

- White bilingual masthead with Marathi and English project names visible together.
- Sand-colored utility/navigation bands and amber section markers.
- Five direct navigation links for the bulletin, services, districts, source status and phone-readiness guide.
- Compact public-information hero, district count panel and labelled latest-status strip.
- More formal, lightly squared service/notice panels with navy text and restrained amber accents.
- English and Marathi copy aligned to citizen-service terminology.
- Updated browser/PWA theme colors and a new shell cache version for the refreshed assets.

The backend, source adapters, geographic matching and alert semantics are unchanged by this design pass.
